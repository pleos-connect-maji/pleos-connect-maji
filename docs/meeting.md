### 확인 및 공유
4. **S9 1단계 안내가 묻히는 문제**: 준비가 즉시 끝나는 경우(시트 이동 0인 탑승자)에 1단계 "자리 맞춰 둘게요"가 완료 안내에 묻힘. 실차에서는 시트가 움직이는 동안 재생되어 문제가 적을 것으로 보이며, 현재는 수정하지 않기로 함. 실차에서 다시 확인 필요
5. **#16 노래 재생 · #17 오디오 포커스 확인**: 노래 설정 UI가 생긴 뒤 청취 담당을 정해야 함
6. **S15 신호 구독 해제 확인 방법 (팀 결정 필요)**
   - 현재 상태: 시작(`start`)은 확인됨. 해제(`stop`)는 미확정
   - 지금까지 시도한 것
     - 뒤로 가기: 메인 화면이 종료되지 않아 `stop()`이 실행되지 않음
     - 작업 비우기 실행(`-f 0x10008000`): 프로세스가 교체되며 이전 프로세스에 `stop` 로그가 남지 않음
   - 선택지
     - A. 개발용 화면에 "구독 해제" 버튼 추가 → `stop()` 직접 호출, 그 뒤 기어 신호가 안 들어오는지 확인 (코드 변경 필요)
     - B. 코드 리뷰로 판단 (`MainActivity`의 `DisposableEffect.onDispose` → `signals.stop()` 호출 확인, 추가 테스트 없음)
     - C. 실차에서 앱을 종료하고 로그 확인 (실차 일정에 포함)
   - 결정 필요: A, B, C 중 선택 (또는 조합)
7. **창문 단위 차이 설명 (발표 자료에 사용 가능)**
   - 현상: 에뮬레이터 콘솔은 0~100%, 앱/SDK는 0~10단계. 10% 단위가 아닌 위치는 가장 가까운 단계로 읽힘
   - 결과: 복구는 읽은 값을 같은 단위로 되돌리므로 차량마다 단위가 달라도 원래 상태가 보장됨 (버그가 아닌 정밀도 차이)
