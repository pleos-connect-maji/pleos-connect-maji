## 2. 테스트 환경

- 에뮬레이터: `Pleos_Connect_v2.1.0`, cold boot (`emulator -avd Pleos_Connect_v2.1.0 -no-snapshot-load`)
- 빌드: develop 디버그 빌드 (`./gradlew.bat :app:installDebug`)
- 탑승자 준비
  - `mom`: 기후 값 있음 (겨울 열선 1단계, 15℃)
  - `kid`: 기후 값 없음 (자리 설정이 떠야 함)
- Virtual Console (`http://127.0.0.1:8088`)을 열어 두고, `adb forward tcp:8088 tcp:8088`로 연결
  - 기어: `/vehicle/gear?gear=Drive|Park`
  - 문: FR(조수석 앞문) 토글
  - 열선·온도: 조수석 패널 또는 `/vehicle/state`로 확인
- 화면 조작: `uiautomator dump`로 버튼 좌표를 찾아 탭
- 음성은 사람이 직접 청취

### S7 상세 (재시작 복원)
- ✅ 맞이 중 `mom` 시작 → 준비 상태에서 앱 강제 종료 → 재실행: "mom 자리 맞추는 중… 열선 1단계, 15℃"와 최종 하차·맞이 취소 버튼이 복원됨
- ✅ 맞이 취소: 조수석 열선이 원래 값(Off)으로 복구됨
- ✅ 시트 복원 (로그 기준): 자리 설정에서 시트 3341ms 기록 → 저장 → 강제 종료·재실행 시 `[#26] 시트 이동 기록 불러옴: 3341ms` → 맞이 취소 시 `시트 되돌릴 시간=-3341ms`, 최종 차이 -6ms (허용 100ms 이내)
  - 차 상태의 `slide` 값은 에뮬레이터에서 갱신되지 않아 로그로만 판단
- ❌→⚠️ 온도 복구: 재시작 뒤 원래 온도를 읽지 못하는 문제
  - 에뮬레이터: 온도 읽기는 막혀 있고 구독만 됨. 재부팅 뒤에는 Virtual Console에서 온도를 한 번 publish해야 읽힘
  - 조치: 시작 시 값 1회 전달 (PR #92, 나경), 맞이 시작 때 온도 저장 후 복구 (PR #91, 임시 대응)
  - 실차에서 시작 시 온도가 읽히는지는 아직 확인하지 못함 (근희)

**S7 남은 확인 (실차)**
1. 실차에서 맞이 시작 시 조수석 온도가 읽히는지 (읽히면 임시 대응은 백업으로만 남음)
2. 실차에서 시트 복원 후 원래 위치로 돌아오는지
